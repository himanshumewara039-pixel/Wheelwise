# 🚗 WheelWise – Vehicle Rental Management System

WheelWise is a Vehicle Rental Management System designed to simplify vehicle rental operations such as vehicle management, customer management, rental booking, payment records, and vehicle availability tracking.

The project combines **C++ OOP concepts, file handling, and Node.js** to create a practical rental management solution.

---

## 🎯 Project Objective

The main objective of WheelWise is to provide an easy-to-use system for managing vehicle rentals digitally.

It helps manage:

- 🚗 Vehicles
- 👤 Customers
- 📋 Rental bookings
- 💳 Payments
- 🪑 Vehicle availability
- 📁 Records using file handling

---

## ✨ Features

- Vehicle registration and management
- Customer record management
- Vehicle availability checking
- Rental booking
- Payment record management
- Unique vehicle ID validation
- File-based data storage
- C++ Object-Oriented Programming
